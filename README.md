# AI-Pretest MesSage · AIPM 3.0

Отдельное Streamlit-приложение для оценки рекламного ролика по трём компонентам:

- **AIPM 1.0** — заметность;
- **AIPM 2.0** — запоминаемость;
- **Message Delivery** — считываемость главной идеи.

Итоговый AIPM 3.0 — нормированное произведение трёх индексов. Вместо генеративных
рекомендаций приложение показывает, что в ролике работает и что ограничивает
результат, с детализацией по бизнес-группам признаков.

## Что находится в репозитории

```text
streamlit_app.py                # вход и навигация
app_pages/video_pretest.py      # интерфейс видео-претеста
aipm3/                          # inference и бизнес-интерпретация
artifacts.py                    # загрузка замороженных моделей из Secrets
scripts/build_local_artifacts.py
requirements.txt
packages.txt                    # системный ffmpeg
```

Модели, обучающие таблицы и API-ключи в GitHub не хранятся. Три замороженных
артефакта передаются через Streamlit Secrets в base64.

## Локальный запуск

1. Создать окружение и установить `requirements-dev.txt`.
2. Упаковать эталонные артефакты командой `scripts/build_local_artifacts.py`, передав
   `--aipm1-model`, `--aipm2-model`, `--md-bundle` — пути к замороженным моделям — и
   существующему `secrets.toml` с `VSELLM_API_KEY`.
3. Запустить `streamlit run streamlit_app.py`.

## Контракт разметки (2026-09-08)

- AIPM 1.0: полный оригинальный промпт `genai_pretest_gemini.py`, 7 признаков
  и транскрипт, 3 последовательных независимых запроса.
- AIPM 2.0: полный оригинальный промпт `aipm_model_v1.py`, все 31 признака,
  2 последовательных независимых запроса. Нельзя сокращать запрос до признаков,
  выбранных регрессором: это меняет ответы Gemini.
- Для обоих компонентов: `google/gemini-3.1-pro-preview`, temperature=0,
  отдельные сообщения без истории, оригинальные JSON-схемы. Категории — мода
  с первым голосом при равенстве; целые числа — Python `round(mean)`.
- Подготовка видео раздельная: AIPM 1.0 — исходный файл до 15 MB; AIPM 2.0 —
  MP4 до 13 MB, остальные файлы перекодируются с локальными настройками.
  Message Delivery сохраняет собственную процедуру подготовки и extraction.
- Message Delivery: финальный локальный `message_delivery_model.py` от 24.08,
  10 запросов по 3 респондента, 3 транскрипции, 21 recovery-панель по 4 ответа
  и кодирование ответов. Его промпты и вычисления не изменены.

Оригинальные строки/схемы находятся в `aipm3/legacy_contracts.py`; контрольные
суммы указывают снимки локальных исходников. При ошибке AIPM1/AIPM2 результат
по неполному числу итераций не публикуется. JSON результата содержит версию
протокола и отдельные разметки компонентов, серверный `result.json` — также
ответы отдельных итераций. Ключ API в результаты не записывается.

**Эталон AIPM 2.0 подтверждён:** `aipm_v4_recovered.cbm`, 9 признаков.
Он воспроизводит столбец `AIPM_v2(adrecall)` из исходной таблицы произведения
на всех 31 кампаниях, для которых найдена историческая разметка. Альтернативный
`aipm_v4_model.cbm` с 11 признаками не совпал ни в одной из этих 31 кампаний.
Пропуски старого разреженного кэша при replay заменяются на 0; новая разметка
по-прежнему должна содержать все поля схемы. Веса не переобучались.

Приложение проверяет SHA-256 всех трёх артефактов, а не только имена признаков.
Это не позволяет незаметно загрузить другую версию весов через Secrets.
Перед ранговой нормировкой AIPM 2.0 округляется до 4 знаков, как в исходной
таблице; неокруглённый прогноз сохраняется отдельно как `raw_score`.
Итог: `rank_index(AIPM1) × rank_index(AIPM2) × rank_index(MD) / product_mean`.
Референс, среднее произведения и границы классов зафиксированы, не вычисляются
заново по загруженному ролику или текущей пользовательской сессии.

`tests/test_reference_replay.py` сверяет индекс и класс приложения с независимым
локальным расчётом через pandas на всех 47 полных строках исторического
`combo_input.csv` (в одной из 48 строк AIPM2 отсутствует). Этот тест использует
сохранённые оценки, включая исторические OOF/holdout-оценки MD, а не новый
прогон Gemini и не предсказания на обучающей выборке. Он проверяет паритет
вычислений, но не является новой оценкой качества связи с DTB.

Одинаковый протокол не гарантирует побитово одинаковые новые ответы Gemini.
Паритет проверяется на **одинаковых исходных ответах**: признаки и оценки
должны совпадать. `python -m pytest -q` проверяет протокол, число запросов,
округление и, при наличии локальных исходников, прямое совпадение с ними.
Приватные сохранённые ответы используются только локально и не входят в Git.

## Streamlit Community Cloud

1. Создать приложение из этого репозитория, ветка `main`, файл `streamlit_app.py`.
2. В **Advanced settings → Secrets** вставить всё содержимое локального файла
   `SECRETS_FOR_STREAMLIT.toml`.
3. Нажать **Deploy**. Установка `ffmpeg` идёт через `packages.txt`.
